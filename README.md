# Решение

## Задание 1
Различия режимов репликации Master-Slave и Master-Master

Master-Slave репликация:

1. Односторонняя репликация - данные копируются только от мастера к слейву
2. Master - принимает все операции записи и чтения
3. Slave - только для чтения, используется для масштабирования нагрузки на чтение
4. Простая настройка и меньше рисков конфликтов
5. Отказоустойчивость - при падении мастера требуется переключение на слейв
6. Использование: отчеты, аналитика, резервное копирование

Master-Master репликация:

Двусторонняя репликация - оба сервера принимают запись и чтение
1. Оба сервера являются мастерами и могут обрабатывать операции записи
2. Высокая доступность - при падении одного мастера второй продолжает работать
3. Cложность - возможны конфликты данных при одновременной записи
4. Требует механизмов разрешения конфликтов
5. Использование: географическое распределение, высокая доступность

Ключевые различия:

1. Направление репликации - однонаправленная vs двунаправленная
2. Запись данных - только на мастер vs на любой сервер
3. Сложность - простая vs сложная с риском конфликтов
4. Отказоустойчивость - требует ручного переключения vs автоматическое продолжение работы
